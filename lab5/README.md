# Лабораторная работа 5. Модульное приложение обработки числовых рядов

Проект реализует модульное приложение на Python для генерации числовых
рядов, расчёта базовой статистики и сглаживания скользящими средними.
Библиотеки numpy и statistics не используются — только стандартные
инструменты языка.

## Структура проекта

```
num_series_app/
├── num_series/              # пакет с основным кодом
│   ├── __init__.py          # публичный API пакета
│   ├── generator.py         # генерация рядов: random, sine, trend
│   ├── stats.py             # статистика: mean, median, spread, summarize
│   └── moving_average.py    # SMA, центрированное MA, EMA
├── tests/                   # модульные тесты (pytest)
│   ├── __init__.py
│   ├── test_generator.py
│   ├── test_stats.py
│   ├── test_moving_average.py
│   └── test_cli.py
├── conftest.py              # настройка путей для pytest
├── pytest.ini               # конфигурация pytest
├── run_self_tests.py        # запуск тестов без установленного pytest
├── main.py                  # точка входа (CLI на argparse)
└── README.md
```

## Описание модулей пакета num_series

- **generator.py** — три генератора рядов: `random_series` (равномерно
  распределённые числа на отрезке), `sine_series` (синусоида с шумом),
  `trend_series` (линейный тренд с шумом). Все принимают `seed` для
  воспроизводимости и проверяют корректность аргументов.
- **stats.py** — среднее арифметическое, медиана (устойчива к выбросам),
  размах ряда и сводный отчёт `summarize`.
- **moving_average.py** — три алгоритма сглаживания:
  - `simple_moving_average` — SMA через бегущую сумму, O(n) по времени;
  - `centered_moving_average` — центрированное среднее для нечётных окон,
    значение выравнивается по центру окна;
  - `exponential_moving_average` — EMA с коэффициентом сглаживания
    alpha из (0, 1]: EMA[0] = x[0], EMA[i] = alpha*x[i] + (1-alpha)*EMA[i-1].

Все функции валидируют входные данные и выбрасывают ValueError
при некорректных аргументах (пустой ряд, окно больше длины ряда,
alpha вне диапазона и т. п.).

| Параметр   | Значения                  | По умолчанию | Назначение                     |
|------------|---------------------------|--------------|--------------------------------|
| `--kind`   | `random`, `sine`, `trend` | `sine`       | тип генерируемого ряда         |
| `--n`      | целое >= 1                | `20`         | количество точек в ряде        |
| `--window` | целое >= 1, не больше n   | `3`          | размер окна скользящей средней |
| `--alpha`  | число из (0, 1]           | `0.3`        | коэффициент сглаживания EMA    |\
| `--seed`   | целое                     | `42`         | зерно ГПСЧ (воспроизводимость) |

Примеры других запусков:

```
python main.py --kind random --n 50 --window 5 --alpha 0.8 --seed 1
python main.py --kind trend --n 30 --window 7 --alpha 0.5 --seed 100
```

При некорректных аргументах (например, --window больше n) программа
печатает сообщение об ошибке в stderr и возвращает код выхода 1.

## Запуск тестов

Если установлен pytest (установка: pip install pytest):

```
pytest
```

Без установленного pytest — автономная самопроверка:

```
python run_self_tests.py
```

Ожидаемый итог самопроверки: 59 проверок пройдено, 0 провалено, 0 ошибок.
